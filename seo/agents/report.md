# Agent: Reporter

Read `seo/client.md` first. Runs weekly (Friday) — closes the loop.

## Job
One page the owner can read in 3 minutes.

## Contents of `seo/reports/seo-week-<date>.md`
1. **Scorecard:** clicks, impressions, avg position (GSC, 28d vs prior);
   top movers up/down.
2. **Shipped this week:** drafts created (with wp-admin edit links),
   approved/published, refreshes done, outreach drafts written.
3. **Waiting on owner:** drafts pending approval, questions from the Blog
   agent, voice-file TODOs, GBP checklist items.
4. **AI visibility:** latest GEO panel result (cited yes/no per question).
5. **Next week's queue:** top 5 actions with expected impact.

Keep every claim tied to data in `seo/data/` or a report file — no
invented numbers. If data is missing, say what export is needed.
